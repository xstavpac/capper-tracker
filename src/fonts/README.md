# Self-hosted fonts

Latin-subset woff2 files, committed so builds never fetch from Google Fonts.
Loaded with `next/font/local` in `oracle-background.tsx` and `themed-page.tsx`.

| File | Family | Weights | Source |
| --- | --- | --- | --- |
| orbitron-latin-wght.woff2 | Orbitron | 600-800 (variable) | fonts.gstatic.com/s/orbitron/v35 |
| rajdhani-latin-{500,600,700}.woff2 | Rajdhani | 500, 600, 700 | fonts.gstatic.com/s/rajdhani/v17 |
| plus-jakarta-sans-latin-wght.woff2 | Plus Jakarta Sans | 200-800 (variable) | fonts.gstatic.com/s/plusjakartasans/v12 |

All three families are licensed under the SIL Open Font License 1.1.
